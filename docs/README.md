# Documentación fs2-react-app

Guías base del proyecto con Vite + React + TypeScript.

## Índice

1. [Nuevo proyecto Vite + React + TS](./01-nuevo-proyecto-vite.md) — crear, limpiar template, instalar dependencias, correr.
2. [Estructura base](./02-estructura-base.md) — estructura que usamos y cómo iniciar el proyecto.
3. [Crear componentes](./03-componentes.md) — convención con CSS Modules + ejemplos reales (`Button`, `Card`, `Input`, `Menu`).
4. [Wouter: instalación y configuración](./04-wouter.md) — routing liviano + `base` para GitHub Pages.
5. [Deploy en GitHub Pages](./05-github-pages.md) — workflow, configuración y errores comunes.

## Comandos rápidos

```bash
npm install      # instala dependencias
npm run dev      # desarrollo en http://localhost:5173
npm run build    # chequeo TS + build a dist/
npm run preview  # previsualiza el build
npm run lint     # lint con oxlint
```
